# TDR Tree Service Website

A modern multi-page website built for a local tree service business.

## Tech Stack
- Next.js
- React
- Tailwind CSS
- Vercel (deployment)

##  Features
- Responsive design
- Services dropdown navigation
- Multi-page layout (Home, Services, About, Contact)
- Custom wood-themed UI
- Mobile-friendly navigation

## Live Site
https://tdr-tree-service.vercel.app/

##  Project Structure
- /app → pages
- /components → reusable UI
- /public → images & textures
